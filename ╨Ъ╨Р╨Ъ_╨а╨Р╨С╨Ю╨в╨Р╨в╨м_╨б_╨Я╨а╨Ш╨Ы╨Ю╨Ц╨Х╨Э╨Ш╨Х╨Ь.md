# Ясный день 50+ — как работать с приложением

## Один проект вместо множества архивов

Это готовая папка статического веб-приложения. Все файлы должны лежать рядом: `index.html`, `app.js`, `content.js`, `styles.css` и остальные файлы. После публикации ссылки у всех будут одинаковые.

## Как запустить приложение бесплатно через GitHub

1. Войдите в GitHub и нажмите **New repository**.
2. Назовите новый репозиторий, например `yasny-den-50`.
3. Выберите **Public** (публикация через GitHub Pages на бесплатном GitHub обычно требует публичного репозитория). Не загружайте в репозиторий личные результаты, фамилии и другие персональные данные.
4. Нажмите **Create repository**.
5. Откройте репозиторий, выберите **Add file → Upload files**.
6. Распакуйте ZIP. Перетащите **все файлы из распакованной папки**, включая `index.html`, `content.js`, `app.js`, `styles.css`, `manifest.webmanifest` и картинки. Файл `index.html` должен оказаться непосредственно в корне репозитория.
7. Нажмите **Commit changes**.
8. Откройте **Settings → Pages**. В пункте **Build and deployment → Source** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, затем **Save**.
9. Дождитесь появления ссылки в разделе Pages; откройте приложение на телефоне.

Адрес обычно выглядит так: `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/yasny-den-50/`. Это пример, а не опубликованная ссылка.

## Как редактировать

- `content.js` — слова, вопросы, правильные ответы, статьи, список видео и инструкции движений. Это основной редактируемый контент. Меняйте тексты и записи аккуратно, сохраняя запятые, кавычки, скобки и структуру JavaScript.
- `styles.css` — цвета, размеры текста, отступы, карточки и кнопки.
- `app.js` — правила игры, порядок занятий, система профилей, начисление прогресса.
- `index.html` — основная структура и подключение файлов.

Для простой правки: откройте нужный файл в GitHub → значок карандаша **Edit** → измените → **Commit changes**. Изменения обычно появятся на сайте после публикации новой версии.

## Как работают участники и сохранение

При первом запуске введите имя человека. Для следующего нажмите **Сменить участника** → **Добавить человека**. Каждый сможет видеть собственную историю и продолжать незавершённые задания.

Если человек закроет вкладку, а потом откроет **тот же сайт в том же браузере на том же устройстве**, результат останется. Не нужно оставлять браузер открытым. Завершённые занятия и промежуточные ответы сохраняются автоматически. Дыхательная практика при прерывании начинается заново.

Данные хранятся в браузере (localStorage), а не на GitHub. Другие посетители не получают эти записи из репозитория. Однако профили на одном устройстве не защищены паролем.

Для подстраховки: **Сменить участника → Скачать копию**. Если почистили браузер или нужно перенести данные вручную, нажмите **Восстановить из файла**. Импорт заменяет весь локальный список участников после подтверждения.

**Важное ограничение:** другой телефон или другой браузер — это отдельное хранилище. Если нужна автоматическая синхронизация между устройствами, понадобится облачная база данных и система входа. Если браузер очищает данные сайтов, гарантировать сохранение невозможно.

## Следующий этап разработки

После публикации проверим вместе 2–3 участника на разных телефонах, затем сделаем удобный визуальный редактор упражнений, чтобы не менять JavaScript вручную. До этого структура `content.js` уже позволяет добавлять новые вопросы, статьи и ссылки на авторские видео.
