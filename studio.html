Открыть обычное приложение
Публикация обновления1. Нажми «Скачать обновление». Каждая из двух фото-игр хранит свои наборы. Файл content.js будет публичным.
2. На GitHub замени файл content.js скачанным.
3. Нажми Commit changes. Участники увидят новую версию.

Предпросмотр создаёт отдельные тестовые профили и не меняет прогресс настоящих участников. Страница редактора публично доступна по ссылке, но не даёт никому прав изменять файлы GitHub.
