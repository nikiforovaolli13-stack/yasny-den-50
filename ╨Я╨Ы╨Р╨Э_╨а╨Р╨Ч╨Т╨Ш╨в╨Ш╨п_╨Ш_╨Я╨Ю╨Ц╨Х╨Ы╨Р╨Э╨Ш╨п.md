# Ясный день 50+ — реестр пожеланий и решений

Этот файл — источник задач для дальнейшего развития. При каждом обновлении сверять с ним все пожелания пользователя. Не удалять пункты без согласования.

## Уже есть в прототипе
- Аудитория 50+, очень читаемый крупный текст, простая навигация, спокойная тёплая палитра и крупные кнопки.
- Один основной режим 20 минут, дополнительные 15 и 30 минут, без гонки за временем.
- Разнообразные упражнения: память, внимание, логика, речь, бытовые навыки, координация, расслабление.
- Нейрогимнастика с пошаговыми движениями и ссылками на внешние видео; в дальнейшем заменить собственными роликами.
- Короткие полезные статьи без медицинского запугивания и навязчивых утверждений о предотвращении деменции.
- Работа на GitHub Pages без платного хостинга.
- Редактор studio.html: отдельная работа с играми, статьями и видео; проверка черновиков, экспорт content.js.
- Две РАЗНЫЕ игры с фото: «Найди пару» (открывать закрытые карточки попарно) и «Запомни и найди» (показ фото → скрыть → выбрать из нескольких). Фото можно загружать самостоятельно.
- Личные профили нескольких участников на одном устройстве; отдельная история, восстановление незавершённых упражнений после закрытия вкладки, резервные копии.
- Редактирование и изменение порядка отдельных заданий, настройка порядка игр в ежедневном комплексе.
- Автоматическая смена содержимого упражнений по дням для каждого участника и предпочтение того, что не показывалось за последние 7 дней; при достаточном объёме есть приоритет не показанного за 14 дней. В «Найди пару» отдельно отслеживаются использованные фотографии, а не только комбинации. Если вариантов недостаточно, возможны повторы; редактор об этом предупреждает.
- Недельный отчёт для каждого участника: дни с занятиями, задания, разнообразие, самые частые упражнения, мягкая идея на следующую неделю.

## Важно сохранить / дальнейшие задачи
- Пользователь обновляет задания примерно раз в 2 недели; библиотека должна поддерживать 14 дней разнообразия. Для настоящей гарантии нужны достаточные объёмы контента по каждому типу (при 3 раундах в день — минимум 42 самостоятельных варианта для 14 дней).
- Уровни сложности и индивидуальная адаптация с осторожной интерпретацией результатов. Не путать игровые очки с клинической оценкой когнитивных способностей.
- Дополнительные визуальные игры: «Что изменилось на картинке?» и «Запомни расположение предметов» (не путать со старой текстовой «Что исчезло?»).
- Собственное видео для нейрогимнастики, удобная замена внешних роликов.
- В будущем — облачная синхронизация между устройствами и полноценная авторизация (локальные профили не обеспечивают этого).
- Отдельный режим поддержки людей с уже имеющимися когнитивными нарушениями — только после экспертной оценки; пока не смешивать его с основным режимом.
- Проверка упражнений нейропсихологом/гериатром, тестирование на людях 55–75+ и клинически корректная формулировка пользы.
- Удобный предпросмотр каждой игры, возможность менять картинки, слова и правильные ответы без ручного редактирования кода.
- Отдельные игровые раунды и итоги недели должны сохраняться после закрытия вкладки и при обновлении приложения без потери пользовательской истории.

## Ограничения
- Эта версия не проходила клинических испытаний; результаты игр не являются диагнозом или доказательством предотвращения деменции.
- Хранение профилей — localStorage на конкретном устройстве/в браузере. Очистка данных сайта, инкогнито и смена устройства несут риск потери истории. Нужны резервные копии.
- Фото/тексты, опубликованные в публичном GitHub Pages, доступны всем посетителям. Не использовать чужие приватные данные без разрешения.
- Ротация «не повторять 7 дней» выполняется только при достаточном количестве самостоятельных материалов. При нехватке выбирается наименее недавно использованный вариант, но неизбежные повторы возможны.
